# 待裁定表（人工金标准）

## 你要做什么

下面 **8 条**，是「原标注」和「独立盲审」**判断相反**的地方。
每条我都给了**片段全文**，你只需要回答一个问题：

> **这个片段，到底能不能回答这道题？**

在每条的「你的裁定」处写 **`相关`** 或 **`不相关`**（也可以直接回我「1 相关，2 不相关…」）。

判断口径（和两轮标注一致）：
- **相关** = 片段里确实含有答案本身，或回答所必需的关键信息
- **不相关** = 只是同一家公司/同一份年报的其他内容、只是主题沾边、只是同一张表的其他行

> 你裁定完，我用它当**金标准**修正标注 → 重跑五档对比 → 得到经得起追问的数字。
